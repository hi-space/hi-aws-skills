## 실제 소스 vs 데모 대체

실제 환경에서는 커넥터·데이터 소스에서 이 데이터를 직접 가져옵니다. 데모에서는 동일한 흐름을 보여주기 위해 대표 데이터를 로컬 파일로 제공합니다.

| 데이터 | 실제 환경에서는 | 데모에서는 |
|------|------|------|
| 예시 데이터 1 | (실제 소스) | 로컬 CSV (`example.csv`) |
| 예시 데이터 2 | (실제 소스) | 로컬 JSON (`example.json`) |

::: tip 이렇게 설명하면 자연스럽습니다
"실제로는 여기서 바로 가져오지만, 오늘은 같은 데이터를 로컬 파일로 준비했습니다." — 흐름이 끊기지 않는다는 점을 전달할 수 있습니다.
:::
